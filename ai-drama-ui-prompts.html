全局设计系统

在使用任何页面提示词之前，先让AI建立统一的设计语言。以下提示词定义了颜色、字体、间距、圆角、阴影等全局变量，确保所有页面风格一致。

Design System Prompt
你是一位资深UI/UX设计师。请为「AI短剧生成平台」设计一套完整的设计系统（Design System），输出为可直接使用的CSS变量和组件规范。 ## 品牌定位 - 产品名称：DramaFlow（AI短剧一站式生产平台） - 品牌关键词：专业、高效、创意、现代 - 用户群体：短剧创作者、MCN机构、独立制作人 - 设计风格：简洁、克制、注重内容呈现，减少装饰元素 ## 色彩系统 - 主色调：使用深邃的蓝紫色系（Indigo-Violet），传达科技感与创造力 - 背景色：浅灰白，营造干净清爽的画布感 - 表面色：纯白卡片 + 微弱投影，形成层次 - 文字色：深蓝黑（主文字）、灰蓝（辅助文字） - 功能色：绿色（成功）、橙色（警告）、红色（错误） - 强调色：使用主色调的渐变作为关键操作按钮和选中状态 ## 字体系统 - 中文：PingFang SC / Microsoft YaHei - 英文/数字：Inter 或 SF Pro Text - 等宽字体：JetBrains Mono（用于代码、提示词编辑区） - 字号层级：12px（辅助）、14px（正文）、16px（小标题）、20px（大标题）、28px（页面标题） ## 间距系统 - 基于4px网格：4, 8, 12, 16, 20, 24, 32, 40, 48, 64 - 卡片内边距：20px - 页面内容区最大宽度：1200px ## 圆角与阴影 - 圆角：8px（按钮/输入框）、12px（卡片）、16px（弹窗） - 阴影：使用低透明度阴影，营造浮层感而非沉重感 - 卡片：0 1px 3px rgba(0,0,0,0.04), 0 1px 2px rgba(0,0,0,0.06) - 悬停：0 4px 12px rgba(0,0,0,0.08) ## 组件规范 - 按钮：主按钮（实心渐变）、次按钮（描边）、文字按钮（无边框） - 高度：36px（小）、40px（中）、48px（大） - 最小宽度：80px - 输入框：白色背景，1px浅灰边框，聚焦时边框变为主色 - 标签/徽章：圆角胶囊形，半透明背景 - 侧边栏：深色背景（深蓝黑），白色文字，宽度240px - 顶部导航：白色背景，高度56px，底部1px分割线 ## 图标规范 - 使用 Feather Icons 或 Lucide Icons 风格 - 常规尺寸：16px、20px、24px - 颜色跟随文字色，选中态使用主色 ## 动效规范 - 过渡时间：150ms（微交互）、300ms（面板展开）、500ms（页面切换） - 缓动函数：cubic-bezier(0.4, 0, 0.2, 1) - 保持克制：仅用于状态切换，不做装饰性动画 请将上述设计规范整理为结构化的输出，包含CSS变量定义和关键组件的HTML/CSS示例。

仪表盘 项目列表 数据统计

视频编辑 配音字幕 时间轴
设计要点：后期工作台采用「素材-预览-片段」三栏布局，中央视频预览区是视觉焦点，左右两侧是功能面板。时间轴设计借鉴了专业剪辑软件的逻辑，但做了大幅简化——只保留镜头分段、字幕、音频三个轨道。左侧Tab面板将配音、字幕、BGM、转场四大功能收纳在有限空间内，通过Tab切换降低认知负担。

使用技巧

以下技巧帮助你更好地使用这套提示词，获得更精准的设计输出。

Tip 01
先跑设计系统，再跑页面
务必先使用「全局设计系统」提示词建立统一的CSS变量和组件规范，再依次输入各页面提示词。这样可以确保所有页面的颜色、字体、间距完全一致。
Tip 02
保留设计系统上下文
在同一个对话会话中依次输入提示词，让AI记住之前建立的设计规范。每个页面提示词中都包含了「使用前面定义的设计系统」这句话，帮助AI保持一致性。
Tip 03
调整具体参数
提示词中的颜色、尺寸、间距都是建议值。你可以根据自己的品牌调性修改主色调（如改为暖橙色适合甜宠剧平台），或调整信息密度（如减少卡片间距适合信息密集型产品）。
Tip 04
迭代优化单页面
如果某个页面的设计不满意，可以追加提示词进行微调，例如：「请将角色列表从横向滚动改为纵向列表，每行显示角色名称、头像和3个最新表情」。
Tip 05
适配移动端
当前提示词主要面向桌面端设计。如需移动端适配，可在每个页面提示词末尾追加：「请同时提供该页面在375px宽度移动端的响应式布局方案」。
Tip 06
控制输出粒度
如果只需要某个页面的特定模块，可以截取提示词中的对应段落使用。例如只需要「剧本工厂」的灵感输入部分，可以单独提取那段描述。
